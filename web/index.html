이 앱의 기준과 개인정보 처리

색을 탐색하는 도구, 사람을 판단하는 도구가 아니야.

12개 계절 팔레트는 제작자가 구성한 비교용 예시야. 진단 기관마다 분류와 색이 다를 수 있고, 앱의 팔레트가 표준이나 정답은 아니야. 이미 진단을 받았다면 해당 진단의 실제 색표를 우선해.

앱은 sRGB → CIELAB(D65) → CIEDE2000으로 색 차이를 계산해. 밝기는 L*, 색도는 √(a*²+b*²)이야. 피부 사진에서 계절·웜쿨·매력을 추론하지 않고, 외모 점수나 정확도 백분율을 만들지 않아.

사진 처리는 브라우저 메모리에서 이루어져. 서버 업로드, 분석 API, 광고, 추적 코드, 외부 폰트가 없어. 사용자가 저장한 색과 팔레트 이름만 브라우저 저장소에 남아. 앱 파일은 오프라인 사용을 위해 캐시될 수 있어. 호스팅 제공자는 일반적인 접속 로그를 보관할 수 있어.

링크 복사는 선택한 색·비교 색·팔레트·사용 위치만 URL의 # 뒤에 담아. 사진과 컬렉션은 포함하지 않아. 링크를 전달받은 사람은 해당 색 설정을 볼 수 있어.

# color, me — 나다운 컬러 스튜디오

사진 전송, 계정, API 키, 유료 모델 없이 사용하는 퍼스널 컬러 **비교·탐색 앱**이야. 사람의 외모를 채점하거나 사진 한 장으로 계절 톤을 단정하지 않아. 좋아하는 색을 포기시키기보다, 실제로 활용할 수 있는 조합을 찾는 데 집중했어.

## 바로 실행

Node.js 20 이상이 있다면 패키지 설치 없이 실행해.

```sh
npm start
# http://127.0.0.1:4173
```

Python 3만 있다면 아래 명령도 가능해.

```sh
python app.py
# http://127.0.0.1:7860
```

HTML을 파일 탐색기에서 직접 여는 대신 위 로컬 서버를 사용해. 종료는 `Ctrl+C`야. 서버는 기본적으로 내 기기의 루프백 주소에서만 접속할 수 있어.

## 달라진 점

| 영역 | v2 기능 |
| --- | --- |
| 색 비교 | HEX·RGB·피커, CIEDE2000 색 차이, 밝기·색도, 고정 색과 나란히 비교 |
| 팔레트 | 봄·여름·가을·겨울 12개 예시 + 톤을 몰라도 쓰는 자유 탐색 |
| 활용 | 상의·하의·소품에 따른 조합, 편안한/선명한 조합 전환 |
| 사진 | 기기 내 JPG·PNG·WebP 처리, 실제 클릭·드래그 좌표, 키보드 선택, 대표색 최대 5개 |
| 컬렉션 | 기기 내 최대 48색, 이름, 삭제·되돌리기, JSON 백업·복원, PNG 컬러 카드 |
| 공유 | 사진 없이 선택한 색 설정만 담은 URL fragment 링크 |
| 운영 | 런타임 외부 의존성 0개, API 호출 0개, 정적 배포, 앱 셸 오프라인 캐시 |

v1의 사진 선택이 언제나 중앙을 읽던 동작을 교체했어. 회색·검정·흰색도 대표색에서 임의로 제외하지 않아. 입력 오류, 저장소 차단, 손상된 백업, 큰 이미지, 늦은 이전 사진 응답을 방어해.

## 비용과 개인정보

앱 기능에는 유료 API, 모델 다운로드, 로그인, 데이터베이스가 필요 없어. 로컬 사용에 서버 구독도 필요 없어. 인터넷에 배포할 경우에는 선택한 호스팅의 요금·트래픽 한도가 별도로 적용돼. 호스팅까지 무조건 영구 무료라고 보장하지 않아.

사진은 브라우저 메모리에서만 처리하고 업로드하거나 저장소에 기록하지 않아. 사진 지우기·페이지 이탈 시 참조를 해제해. 저장한 색·톤·사용자가 붙인 이름은 해당 브라우저의 localStorage에 남아. 브라우저 데이터를 지우면 사라질 수 있으니 JSON 백업을 사용해. 링크에는 사진·이름·컬렉션이 들어가지 않아.

광고·분석 SDK·외부 폰트가 없어. 앱 파일의 다운로드와 사용자가 직접 여는 근거 링크는 네트워크를 사용해. 호스팅 제공자의 일반 접속 로그는 별개야.

## 개발·검증·배포

```sh
npm test             # Node 내장 테스트 러너, 별도 설치 없음
npm run build        # dist 생성, JS 문법/용량 검사
npm run check        # 테스트와 빌드
node scripts/serve.mjs --dist
```

`dist/`만 정적 호스팅에 배포해. 저장소 전체나 v1의 개인 측색 보고서를 웹 루트에 올리지 마. 경로는 상대 주소라 하위 경로도 지원하도록 작성했어. `/personal_color_match/` 경로 검사는 다음과 같아.

```sh
BASE_PATH=/personal_color_match/ node scripts/serve.mjs --dist
```

오프라인 캐시는 HTTPS 또는 localhost에서 지원하는 브라우저가 필요해. 개발 중에는 localhost 캐시를 기본적으로 꺼 두었어. `?offline`을 붙이면 로컬에서도 등록해. 첫 방문과 앱 셸 캐시 완료에는 네트워크가 필요하며, 새 버전은 기존 앱 탭을 닫은 뒤 활성화되는 방식이야. 파일을 더블클릭한 `file://` 실행은 지원하지 않아.

계산 근거·한계는 [docs/METHOD.md](docs/METHOD.md), 실제 검증 범위와 남은 항목은 [docs/QA.md](docs/QA.md)에 있어. **단위 테스트 통과와 실제 브라우저 사용성 검증은 다른 일이야.**

## 구조

`web/src/color.js`는 계산, `palettes.js`는 예시 데이터, `state.js`는 저장·공유 계약, `photo.js`와 `palette-worker.js`는 이미지 처리, `app.js`는 UI를 담당해. 빌드·서버는 Node 표준 라이브러리만 사용해. `app.py`는 Python 표준 라이브러리 실행기일 뿐 이미지나 사용자 정보를 처리하는 백엔드가 아니야.

## v1 보존과 복구

v1 전체는 `archive/v1-before-local-first-rebuild` 브랜치와 커밋 `3a1782db696dc7ce2571cd23d4f25ae0be617172`에 보존했어. v2에서 오래된 Gradio/LLM 의존성과 개인 참고 HTML은 제거하지만 Git 이력 자체는 지우지 않아. 기존 HTML에 민감한 정보가 있다면 과거 이력의 공개 상태는 별도로 검토해야 해.

강제 푸시 대신 v2 개편 커밋을 `git revert`하면 변경을 되돌릴 수 있어. 기존 Python 모듈 API와 v1 JSON 포맷은 v2와 호환되지 않아. 새 JSON 백업은 `version: 2`를 사용해.

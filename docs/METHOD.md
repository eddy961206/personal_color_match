# 계산 방법·표현 원칙

## 계산이 말하는 것과 말하지 않는 것

앱은 선택한 두 sRGB 색의 차이를 계산해. 특정 사람이 얼마나 아름다운지, 어떤 계절 톤인지, 해당 옷이 어울릴 확률을 계산하지 않아. 팔레트와의 거리를 정확도 백분율로 바꾸지 않고, 결과를 '비추천'이나 '피해야 할 색'으로 해석하지 않아.

12개 팔레트는 제작자가 구성한 탐색용 예시야. 봄 브라이트의 베이스·액센트 색은 v1 자료를 이어받았고, 나머지는 예시 데이터로 추가했어. 임상적·표준화된 진단 데이터가 아니며, 분류 경계와 색상표가 보편적으로 검증됐다고 주장하지 않아.

## 색 차이

1. HEX를 8비트 sRGB로 해석하고 전달함수를 선형화해.
2. D65 기준 XYZ 및 CIELAB으로 변환해.
3. CIEDE2000(kL=kC=kH=1)으로 팔레트 각 색과의 거리를 계산해.
4. 가까운 3색과 실제 거리, L* 및 C*=sqrt(a*²+b*²)를 보여줘.

계산은 원래 코드로 구현했어. 참고 논문의 배포 프로그램을 복사하지 않았어. 수치 검증에는 공개된 34개 테스트 쌍을 사용하고 절대 오차 0.0001 이내인지 검사해.

출처: G. Sharma, W. Wu, E. N. Dalal (2005), *The CIEDE2000 Color-Difference Formula: Implementation Notes, Supplementary Test Data, and Mathematical Observations*.

- 저자 자료: https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/
- 수치 검증 자료: https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/dataNprograms/ciede2000testdata.txt

## 사진 처리

JPG·PNG·WebP 헤더에서 크기를 먼저 확인해. 12MB, 2,400만 화소, 한 변 12,000픽셀 제한이 있어. 디코딩 후에도 크기를 검증하고, 긴 변 960픽셀로 줄인 별도 원본 캔버스를 유지해. 화면 표시용 선택선은 샘플링에 섞이지 않아.

대표색은 최대 약 32,000픽셀을 결정론적으로 샘플링하고, RGB 양자화 후 Lab 공간의 가중 군집화 10회로 추출해. 가능하면 Web Worker를 사용하고, 미지원·오류·시간 초과 시 같은 로컬 알고리즘으로 대체해. 투명도 0.125 미만 픽셀은 제외하고 다른 픽셀은 alpha 가중치를 사용해. 비율은 이미지 전체 면적의 엄밀한 측정값이 아니라 샘플의 근삿값이야.

지점 선택은 주변 5×5픽셀, 영역 선택은 해당 사각형의 선형광·alpha 가중 평균이야. 선택 좌표는 표시 크기에서 원본 캔버스 크기로 변환해. 늦게 도착한 이전 요청은 generation 검증으로 버리고, 이전 worker 오류가 새 worker를 종료하지 못하도록 막아.

사진의 조명·색 보정·화이트밸런스·압축·화면 색관리 때문에 실제 원단이나 피부의 측색값과 다를 수 있어. EXIF 방향은 브라우저 디코더에 맡겨. 얼굴 감지·생체정보 분석·자동 계절 진단은 하지 않아. HEIC는 JPG 변환이 필요해.

디코딩 근거: https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap

## 접근성과 심리적 설계

색 견본의 글자는 검정/흰색 중 더 높은 WCAG 대비를 선택해. 대비 수치는 화면 글자의 참고값이지 옷의 어울림 지표가 아니야. 키보드 탭 탐색, 사진 좌표 이동, 포커스 표시, 색 이름/HEX 병기, reduced-motion, 오류 안내를 구현했어. 이것이 전체 WCAG 적합성 인증을 뜻하지는 않아.

기준: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

선택의 주도권을 사용자에게 남겨 두는 것을 설계 목표로 삼았어. 기본 동선을 단순하게 하고, 복잡한 수치를 접을 수 있게 하며, 삭제를 되돌릴 수 있게 했어. 취향을 부정하거나 구매·재방문을 압박하는 문구를 넣지 않았어. 심리적 효과나 사용성 개선을 실제 사용자 실험으로 입증한 것은 아니야.

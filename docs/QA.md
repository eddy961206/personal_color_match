# v2 검증 기록

검증일: 2026-10-03. 대상: 이 문서와 함께 제공한 v2 소스.

## 이 환경에서 실제 통과

- Node.js 22.16.0 / npm 10.9.2에서 `npm run check` 성공.
- Node 내장 단위 테스트 59개 통과, 실패·건너뛰기 0개.
- CIEDE2000 공개 검증 쌍 34개, 양방향 결과와 오차 0.0001 검사.
- HEX·RGB 경계 입력, 12개 팔레트, 색 차이 대칭/동일색, 글자 대비, 투명도·중성색·대표색 결정성 검사.
- 공유 fragment 왕복, 백업 손상·스키마·용량·중복·최대 개수, 저장소 오류, 삭제 복구 병합 검사.
- 사진 헤더/해상도·용량 제한, 표시 좌표 변환, 실제 좌표 픽셀 영역 검사.
- 가짜 캔버스·디코더·worker를 사용한 단위 테스트에서 클릭/역방향 드래그/키보드/취소/늦은 디코드/늦은 worker 오류/자원 해제 검사.
- 앱 JS 문법 검사와 정적 파일 용량 예산 검사. 외부 API 클라이언트·외부 모듈 import·unsafe DOM 문자열 삽입 정적 검사.
- 로컬 HTTP 서버에 HTTP 요청을 보내 index.html 200 응답 확인.

빌드별 정확한 파일 수·용량·revision은 `npm run build`의 출력과 `dist/build-info.json`에서 확인해. gzip 합계는 각 파일을 개별 압축한 크기의 합이며, 호스팅 전송 헤더나 최초 캐시 비용은 포함하지 않아.

## 완료했다고 주장하지 않는 항목

현재 실행 환경의 Chromium은 관리자 URLBlocklist 정책으로 모든 주소 탐색이 차단돼. Playwright의 localhost 방문은 `net::ERR_BLOCKED_BY_ADMINISTRATOR`로 실패했어. 정책을 해제하거나 우회하지 않았어.

따라서 이 기록만으로 **실제 브라우저 렌더링, 모바일 조작, 화면 스크린샷, 클립보드/다운로드, 실제 사진 디코딩, 브라우저 저장소, Service Worker 오프라인 동작이 검증됐다고 볼 수 없어.** 단위 테스트의 가짜 캔버스와 실제 브라우저는 구별해야 해.

멀티에이전트 실행 기능을 확보하지 못해 단일 에이전트가 구현·검토했어. 다른 모델의 독립 리뷰, 사용자 대상 사용성 실험, iOS/Android 실기기 검사, 전체 WCAG 인증은 수행하지 않았어. 인터넷 호스팅이나 공개 전환도 실행하지 않았어.

## 배포 전 수동 브라우저 점검

1. 320·390·768·1440px에서 화면 잘림·가로 넘침·클릭 영역·대비를 확인해.
2. 색 입력·톤 전환·RGB·고정 비교·조합 전환·탭 키보드 이동을 확인해.
3. 이름 수정 직후 삭제, 삭제 복구, 새로고침 보존, 저장소 차단 안내, 손상된 JSON과 정상 JSON 복원을 확인해.
4. PNG 카드와 공유 링크를 열어 사진·이름 등 의도하지 않은 정보가 없는지 확인해.
5. 색이 나뉜 테스트 사진에서 좌/우 클릭·드래그·키보드가 실제 위치의 색을 읽는지 확인해. 연속 업로드·취소·큰 파일·투명 사진도 포함해.
6. 개발자 도구의 Network에서 외부 전송이 없는지 확인하고, HTTPS와 하위 경로에서 오프라인 재방문·새 버전 갱신을 확인해.

CI 워크플로는 계산·계약·문법·빌드를 검사해. GitHub에서 CI 실행 결과를 별도로 확인하지 않았다면 CI 성공을 전제하지 마.
